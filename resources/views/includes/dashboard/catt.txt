🔹 1. Dashboard

Ringkasan total penjualan, pesanan, produksi, stok pupuk, dan pendapatan.

Grafik penjualan harian/bulanan.

🔹 2. Master Data

Untuk data inti yang jarang berubah.

Data Role — kelola jenis role (Admin, Petugas, Customer).

Data Pengguna — kelola akun user (admin, pegawai, dsb).

Data Customer — daftar pelanggan.

🔹 3. Produk & Produksi

Untuk manajemen pupuk dan proses produksinya.

Data Pupuk — CRUD data pupuk (nama, jenis, harga, stok, status).

Data Produksi — mencatat proses produksi pupuk (tanggal, jumlah karung, status).

🔹 4. Penjualan / Transaksi

Untuk manajemen pesanan dan pembelian pelanggan.

Pesanan — daftar semua pesanan (dengan status “baru”, “proses”, “selesai”).

Detail Pesanan — rincian barang per pesanan.

Pembayaran — verifikasi pembayaran, upload bukti, ubah status pembayaran.

Pengiriman — data pengiriman (alamat, tanggal kirim, tanggal terima, status).

🔹 5. Laporan

Untuk melihat rekap data dan mencetak laporan.

Laporan Penjualan — daftar transaksi per periode (harian, mingguan, bulanan).

Laporan Produksi — jumlah produksi pupuk per periode.

Laporan Pembayaran — status pembayaran per pesanan.

Laporan Stok — ketersediaan pupuk terkini.

🔹 6. Pengaturan

Untuk konfigurasi umum sistem.

Profil Pengguna — ubah nama, email, password, alamat, telepon.

Pengaturan Website / Sistem — (opsional, misal nama toko, alamat, logo).
